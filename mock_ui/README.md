# Tone 오프라인 데모 (mock UI)

네트워크나 서버 없이 Tone을 시연하기 위한 화면이다. 실제 Tone 화면 코드(`tone/src`)를
그대로 쓰고, 백엔드만 미리 준비한 음성과 시나리오로 바꿨다.

- **위쪽:** 실제와 같은 Tone 채팅 화면. 프로필 3명(종찬·재웅·경택)이 있다.
- **아래쪽:** 포스터의 System Architecture 그림. 지금 진행 중인 단계가 켜진다.
  `P` 키나 `숨기기`로 접으면 채팅 화면만 남는다.

## 실행

`site/index.html`을 더블클릭해서 Chrome이나 Edge로 연다. 설치·빌드·인터넷이 필요 없다.
발표용 PC로 옮길 때는 `site/` 폴더를 통째로 복사한다(`audio/` 폴더가 함께 있어야 소리가 난다).

## 시연 순서

1. 프로필을 고른다(예: 재웅).
2. 상대(예: 종찬) 대화방에서 마이크 버튼을 **누르고 있다가 뗀다**. 실제 마이크는 쓰지 않는다.
3. 분석이 끝나면 초안이 뜬다. 문장과 감정을 확인하고 `전송`을 누른다.
4. `나` → `프로필 전환`으로 받는 사람(종찬)이 되어, 대화방에서 메시지의 재생 버튼을 누른다.
   합성 단계가 차례로 켜진 뒤 보낸 사람의 목소리로 소리가 난다.

- 파이프라인 패널의 `화자 ref 음성 ▶ 듣기`로 보낸 사람이 등록해 둔 목소리를 들려줄 수 있다.
- 초안 화면의 재생 버튼은 감정 원본(`source.wav`)을 들려준다.
- `처음부터`를 누르면 메시지와 설정이 지워지고 프로필 선택으로 돌아간다.

프로필마다 보내는 메시지가 하나씩 정해져 있다.

| 프로필 | 감정 | 음성 세트 |
|---|---|---|
| 종찬 | 기쁨 | `audio/happy` |
| 재웅 | 분노 | `audio/angry` |
| 경택 | 두려움 | `audio/fearful` |

## 준비된 음성에 대해

세트마다 파일이 세 개 있다.

| 파일 | 내용 | 화면에서 쓰이는 곳 |
|---|---|---|
| `reference.wav` | 화자가 등록한 목소리 샘플 | 파이프라인의 `화자 ref 음성 ▶ 듣기` |
| `source.wav` | 감정이 담긴 발화 | 초안 화면의 녹음 재생 |
| `output.wav` | 합성 결과 | 받은 메시지 재생 |

`output.wav`는 `reference.wav`와 같은 문장을 말한다. 그래서 채팅 메시지의 문장은 합성
결과에 맞췄고, 초안에서 들리는 `source.wav`의 문장과는 다르다.

문장은 음성을 Whisper로 받아 적은 것이다. 발표 전에 들어 보고 틀린 곳은
`src/scenario.ts`에서 고친 뒤 다시 빌드한다.

## 고쳐서 다시 만들기

```
cd mock_ui
npm install     # 처음 한 번
npm run build   # site/ 를 다시 만든다
npm run dev     # 고치면서 볼 때 (http://localhost:3100)
```

| 파일 | 내용 |
|---|---|
| `src/scenario.ts` | 프로필, 음성 세트, 문장 |
| `src/mockApi.ts` | 가짜 백엔드. 각 호출이 파이프라인의 어느 단계인지와 머무는 시간 |
| `src/PipelinePanel.tsx`, `src/mock.css` | 파이프라인 패널 |
| `src/main.tsx` | 처음 상태(프로필 3명) 만들기 |
| `vite.config.ts` | `tone/src`의 어떤 모듈을 mock으로 바꿔 끼우는지 |
| `tools/build_assets.py` | 원본 음성을 브라우저용(16비트 WAV)으로 변환 |

`tone/src`의 화면을 고치면 이 데모에도 반영된다. 다만 `site/`는 빌드 결과물이라
`npm run build`를 다시 해야 바뀐다.

음성을 바꿀 때는 아래를 실행하고, 출력되는 `source.wav`의 길이와 크기를
`src/scenario.ts`에 옮겨 적은 뒤 빌드한다.

```
endpoint/.venv/Scripts/python.exe mock_ui/tools/build_assets.py <음성 세트 폴더>
```
