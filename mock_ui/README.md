# Tone 오프라인 데모 (mock UI)

발표장에서 네트워크가 안 될 때 실제 시스템 대신 보여 주는 로컬 데모다. 실제 Tone 화면
코드(`tone/src`)를 그대로 쓰고, 백엔드만 미리 준비한 음성과 시나리오로 바꿨다.
시스템 구조와 전체 설명은 포스터가 맡는다.

## 실행

`site/index.html`을 더블클릭해서 Chrome이나 Edge로 연다. 설치·빌드·인터넷이 필요 없다.
발표용 PC로 옮길 때는 `site/` 폴더를 통째로 복사한다(`audio/` 폴더가 함께 있어야 소리가 난다).

## 자동 시연

시작 화면에서 고른다. 가상 커서가 실제 화면을 순서대로 조작한다.

| 버튼 | 내용 | 길이 |
|---|---|---|
| `자동 시연 시작` | 목소리가 등록된 상태에서 녹음 → 전송 → 상대측 재생 | 약 30초 |
| `처음부터 보기` | 프로필 생성 → 목소리 등록 → 녹음 → 전송 → 상대측 재생 | 약 1분 |
| `직접 조작하기` | 자동 시연 없이 프로필 4명(종찬·재웅·경택·태원)으로 바로 쓴다 | — |

길이는 지금 들어 있는 음성 기준이다. 음성을 바꾸면 그 길이만큼 달라진다.

| 단계 | 화면에서 일어나는 일 | 들리는 소리 |
|---|---|---|
| 프로필 생성 (처음부터 보기만) | 보내는 사람(종찬)의 프로필을 새로 만든다 | — |
| 목소리 등록 (처음부터 보기만) | 정해진 문장을 읽어 목소리를 등록한다 | `reference.wav` |
| 녹음 | 상대(재웅)를 고르고, 마이크를 눌러 말한다 | `source.wav` |
| 전송 | 인식된 문장과 감정을 확인하고 전송한다 | — |
| 상대측 재생 | 재웅 프로필로 바꿔 받은 메시지를 재생한다 | `output.wav` |

시연이 끝나면 그 화면에 멈추고, 이어서 직접 조작할 수 있다. 위쪽 줄의 `자동 시연`,
`처음부터 시연`으로 다시 시작하고, `초기화`로 메시지와 설정을 지운다.

| 키 | 동작 |
|---|---|
| `Space` | 일시정지 / 계속 |
| `Esc` | 정지 |
| `P` | 시스템 구조 그림 보기 / 숨기기 |

## 시스템 구조 그림 (선택)

기본은 숨겨져 있다. `구조 보기`나 `P`를 누르면 화면 아래에 포스터의 System Architecture
그림이 나오고, 지금 단계와 그 구역이 강조된다.

1. 분리 — 음성을 Whisper STT와 emotion2vec에 넣는다
2. 분리 결과 — 텍스트와 1024차원 감정 벡터로 나뉜다
3. 압축 — FSQ 인코더가 1024차원을 8차원으로 줄인다
4. 양자화 — 8차원 격자를 24bit 코드로 만든다
5. 전송 — 텍스트와 24bit를 한 번에 보낸다
6. 복원 · 저장 — 서버가 24bit를 다시 1024차원으로 늘려 MySQL에 저장한다
7. 합성 준비 → 합성(Qwen3-TTS) → 전달(gRPC 스트리밍) → 재생

그림이 펼쳐져 있으면 단계마다 설명을 읽을 시간을 주느라 진행이 느려진다(짧은 시연이
약 50초). 숨겨져 있으면 실제 시스템처럼 빠르게 지나간다.

## 프로필과 대화 기록

프로필은 4명이고, 음성은 그 사람의 번호 폴더에 둔다.

| 번호 | 프로필 | 음성 폴더 |
|---|---|---|
| 0 | 종찬 | `public/audio/0/` |
| 1 | 재웅 | 없음 |
| 2 | 경택 | 없음 |
| 3 | 태원 | 없음 |

처음부터 대화가 오가 있는 것처럼 보이도록 가짜 대화 기록(`src/history.ts`)이 들어 있다.
대화 목록과 감정 통계(`나` → `통계`)가 이 기록으로 채워진다.

- 대화 기록의 메시지는 음성이 없다. 재생을 누르면 음성이 없다는 안내가 뜬다.
- 데모에서 새로 보낸 메시지만 준비된 음성으로 들린다.
- 음성이 준비된 사람은 종찬뿐이다. 나머지 프로필로는 대화 기록과 통계만 볼 수 있고,
  녹음을 누르면 준비된 음성이 없다는 안내가 뜬다.

## 음성과 감정 코드 넣기

보내는 사람의 번호 폴더에 세 파일을 같은 이름으로 넣는다.

| 파일 | 내용 | 들리는 곳 |
|---|---|---|
| `reference.wav` | 목소리 등록 때 정해진 문장을 읽은 소리 | 목소리 등록 |
| `source.wav` | 상대에게 메시지를 보낼 때 말한 소리 | 녹음 |
| `output.wav` | 받는 쪽에서 합성된 소리 | 상대측 재생 |

정해진 문장은 "안녕하세요, 오늘 날씨가 참 좋아서 산책하기 딱 좋은 날인 것 같네요. 주말에는
보통 집에서 책을 읽거나 가까운 카페에 가서 시간을 보냅니다."이다.

지금 종찬(`0/`)의 세 파일은 모두 실제 시스템에서 나온 것이고, `src/scenario.ts`의 문장·감정·감정
코드도 그 녹음을 실제로 인코딩한 결과(`EncodeResult`)를 옮긴 값이다. 다른 사람의 음성을
추가하려면 그 사람의 번호 폴더를 만들고 `VOICE_SETS`에 항목을 더한다.

1. 파일을 번호 폴더에 넣는다.
2. 브라우저용으로 변환하고 길이·크기를 확인한다. 16비트가 아닌 파일은 그 자리에서 변환된다.

   ```
   endpoint/.venv/Scripts/python.exe mock_ui/tools/build_assets.py
   ```

3. `src/scenario.ts`에서 그 번호의 항목을 고친다.
   - `text`: 합성 결과가 말하는 문장(채팅 메시지로 보인다)
   - `emotion`, `emoType`, `emotionScore`: 감정 이름, 번호, 확신도
   - `referenceDuration`: 2번에서 나온 `reference.wav` 길이
   - `sourceDuration`, `sourceBytes`: 2번에서 나온 `source.wav` 길이와 크기
   - `emotionCode`: DB에 저장된 감정 코드. FSQ 인덱스 8개, 각각 0~7.
     예: `emotionCode: [3, 7, 0, 5, 2, 6, 1, 4]`
4. `npm run build`로 `site/`를 다시 만든다.

`emotionCode`를 넣으면 구조 그림의 8d 막대와 24bit 칸이 그 값을 그대로 그린다. 넣지 않으면
크기만 맞춘 장식으로 그려진다(1024d 막대는 항상 장식이다).

자동 시연에서 누가 누구에게 보내는지는 `src/scenario.ts`의 `AUTOPLAY`에서 바꾼다.

## 고쳐서 다시 만들기

```
cd mock_ui
npm install     # 처음 한 번
npm run build   # site/ 를 다시 만든다
npm run dev     # 고치면서 볼 때 (http://localhost:3100)
```

| 파일 | 내용 |
|---|---|
| `src/scenario.ts` | 프로필, 음성 세트, 문장, 감정 코드, 자동 시연의 보내는 사람·받는 사람 |
| `src/history.ts` | 처음부터 들어 있는 가짜 대화 기록 (음성 없음) |
| `src/autoplay.ts` | 자동 시연 순서(어떤 버튼을 언제 누르는지) |
| `src/mockApi.ts` | 가짜 백엔드. 각 호출이 구조 그림의 어느 단계인지와 걸리는 시간(`QUICK`, `EXPLAIN`) |
| `src/PipelinePanel.tsx`, `src/mock.css`, `src/autoplay.css` | 파이프라인 패널과 시연 화면 스타일 |
| `src/AutoplayBar.tsx` | 위쪽 제어 줄과 시작 화면 |
| `src/main.tsx` | 화면 배치와 처음 상태 |
| `src/noMetricsDock.tsx` | 오른쪽 아래 시스템 지표 버튼을 빼는 자리 표시 (서버가 없어 측정값이 없다) |
| `vite.config.ts` | `tone/src`의 어떤 모듈을 mock으로 바꿔 끼우는지 |
| `tools/build_assets.py` | `public/audio`의 음성을 브라우저용(16비트 WAV)으로 변환하고 길이·크기를 출력 |

`tone/src`의 화면을 고치면 이 데모에도 반영된다. 다만 `site/`는 빌드 결과물이라
`npm run build`를 다시 해야 바뀐다. 자동 시연은 버튼의 글자와 `aria-label`로 화면을
찾으므로, `tone/src`에서 그 글자를 바꾸면 `src/autoplay.ts`도 맞춰 고쳐야 한다.
